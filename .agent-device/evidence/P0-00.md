## Limitations and follow-up

- Linux ADB mDNS discovery does not currently cross this WSL2 NAT boundary.
  After the phone's wireless-debugging connection port changes, run
  `./.akidev/bin/adb connect PHONE_IP:CONNECTION_PORT`; pairing and connection
  use different ports.
- HyperOS permits the Maestro helper after the on-device installation prompt is
  approved. **USB debugging (Security settings)** and **Install via USB** now
  allow Maestro input injection.
- The dependency mismatch is repaired. Each fresh Maestro invocation may still
  require the on-device helper installation prompt to be accepted.
- The Android system photo picker is outside CaneGuard's selector ownership.
  This Xiaomi picker exposes staged media by timestamp and requires an explicit
  **Done** action; the flow now handles that behavior while keeping app-owned
  selectors intent-based.
- Physical Android evidence covers TFLite, the system picker, managed image
  storage, SQLite persistence, reopening the record, and the persisted result
  and barangay values. The P0-00 baseline flow is repeatable entirely from
  WSL2 on this device.

# Mockup Reference Note

The PNG in this folder was generated to communicate visual direction: cleaner hierarchy, real reference photography, simple green/neutral branding, strong scan action, and reduced decorative noise.

It also contains illustrative concepts that are **not necessarily implemented in the current CaneGuard repository**, such as onboarding/field-list-style screens.

Therefore:

- use it as a mood/layout reference
- do not extract/crop its disease imagery for production
- do not treat its text as authoritative domain copy
- do not add features solely because they appear in the mockup
- use the current repository and the implementation specs in this package as the source of truth
